# AB_OCR 작업 지침

- 사용자 목표: ABBYY FineReader OCR Editor와 유사한 Windows OCR 편집기. 최우선은 한글·한자 인식 정확도.
- 이 프로젝트는 YeonE_OCR와 독립적으로 새로 시작한다. 다른 프로젝트 파일은 요청 없이 수정하지 않는다.
- 시작 시 README.md와 docs/HANDOFF.md를 확인하고 실제 구현 여부와 계획을 구분한다.
- 원본 문서, 원시 OCR 결과, 사람의 교정 결과를 분리하여 보관한다.
- 간체·번체·이체자·문장부호를 사용자 모르게 정규화하지 않는다. 비교용 정규화는 정책을 기록한다.
- 복잡한 표·세로쓰기·혼용 문헌의 품질은 대표 자료와 정답으로 검증한다. 측정 전 동급 성능을 주장하지 않는다.
- API 키와 개인 문서를 소스, 로그, 테스트 자료, 배포물에 포함하지 않는다.
- 로컬 엔진과 외부 API 엔진은 교체 가능한 인터페이스로 분리한다.
- 유료/외부 전송 작업은 사용자가 선택한 엔진·문서·범위로만 실행한다. 기존 사용자 승인을 반복해서 묻지 않는다.
- 저장은 원자적으로 수행하고 재열기·원본 변경 감지·오류 복구를 검증한다.
- UI 작업 스레드와 인식 작업을 분리하고 진행률·취소·완료한 쪽 복구를 지원한다.
- 테스트는 정확도 계산, 원문 보존, 좌표 변환, 작업 저장 등 의미 있는 동작에 집중한다.
