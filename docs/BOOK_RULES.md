# 책 자료와 출력 모양

일반 OCR에서 **PDF 고르기… → 이 책 설정… → 분석하고 HWPX·문자 PDF 만들기**를 선택합니다. 분석 결과를 이 책에 저장하고 일반 OCR의 실행 흐름으로 이어갑니다. 같은 판독을 사용해 편집용 HWPX와 원본 쪽 모양을 유지하는 문자 PDF를 만듭니다.

**원본 대조 · OCR 오독 교정 · 각주 뒤 쪽 경계 검수**는 기본으로 켜져 있습니다. 설치된 OCR과 저장된 비교 판독으로 원본을 대조합니다. 근거가 일치한 글자를 두 출력에 공통 반영하고, 판단이 어려운 후보와 각주 뒤 쪽 경계는 `원본대조.html`에 쪽별로 기록합니다. 사람이 교정한 쪽은 보존합니다.

원본 옆에 같은 이름의 `(인식)` 또는 `(OCR)` PDF가 있으면, 원본과 같은 스캔임을 쪽 이미지로 확인하고 해당 쪽의 글자와 좌표를 대조에 활용합니다. 어느 파일을 참고했는지 검수표에 표시합니다. 오독을 반영할 때는 독립 판독 두 계열의 위치와 앞뒤 글자가 함께 맞아야 합니다.

**양식·출력 → HWPX 책갈피**의 기본값은 **제목마다 하나**입니다. 목차 표제와 본문의 장·절·항목 제목을 한 번씩 등록합니다. **모두 빼기**를 선택해도 회색 원본 쪽 안내는 유지됩니다.

**양식·출력 → HWPX 글자 변환**에서 간체→번체, 한국 표준 한자체, 云/雲, 중문부호를 책별로 지정합니다. **공통 설정 사용**을 고르면 해당 공통 규칙을 따릅니다. **고급 편집**에서 원문 표기 유지와 검수 등급 글자색도 책별로 저장할 수 있습니다. 문자 PDF는 원본 지면과 대조 후 판독한 글자를 보존합니다.

**고급 편집 → 검수 표시를 글자색 중심으로 표시**의 추천값은 켜기입니다. 검수 글자색과 근거는 유지하고 OCR 검수용 형광 배경을 줄입니다.

## 책 설정

**책 자료**에서 참고 OCR과 작업 폴더를 확인합니다. **양식·출력**에서 HWPX 양식을 선택하거나 쪽별 대조본을 지정할 수 있습니다. 자동으로 두 파일을 만들 때는 편집용 HWPX와 자동 읽기 방향을 사용합니다. **고급 편집**에서 제목, 하단 주석, 항목 표지 적용과 스타일 연결을 조정합니다. **이 책 설정 저장**을 누르면 변경을 현재 책에 기록합니다.

**먼저 분석 결과 보기 → HWPX 미리보기**는 적용 전에도 제안된 규칙과 양식으로 대표 최대 5쪽을 실제 HWPX로 만듭니다. 기존 판독을 우선하고, 판독이 없으면 PDF 글자층을 사용합니다. 이미지 전용 스캔의 HWPX 미리보기에는 대표 쪽 판독이 필요합니다. **원문 표기·자동 교정 설정…**에서 문자·문장부호 정리를 조정합니다.

참고 OCR HWPX는 이전 판독 본문이고, 양식 HWPX는 출력 서식입니다. AI 규칙 생성은 PDF 글자층 또는 원본이 일치하는 기존 OCR과 참고 HWPX의 본문을 대조하여 대응되는 구간만 쪽 이미지와 함께 전달합니다. 대응되지 않는 쪽은 보고서에 남깁니다. 글자층과 기존 OCR이 모두 없는 스캔은 참고 HWPX의 대응 구간을 찾을 수 없으므로 PDF 이미지로 분석합니다. 참고 문서는 원본 판독의 정답이나 지시로 취급하지 않습니다.

참고 HWPX가 바뀌면 분석 캐시를 다시 만들며, 생성 후 PDF·양식·참고 HWPX 내용이 달라지면 이전 결과 적용을 차단합니다. 분석 중 두 화면에서 자료 선택이 바뀌어도 이전 결과를 적용하지 않습니다.

## 기존 OCR 재검수·재판독 (1.2.49)

**이 책 설정 → 책 자료 → 기존 OCR 재검수·재판독…** 또는 **설정 → 이 책 → 기존 OCR 재검수·재판독…**에서 기존 작업자료/결과 폴더를 고릅니다. 파일명만 바뀐 PDF도 내용이 일치하면 연결합니다.

- **의심 부분 우선**: 의심 글자·판독 확인 항목·낮은 신뢰도·AI 제안·미완료 기록이 있는 쪽을 선택합니다. 글자 위치만 잘라 읽는 방식이 아니라 해당 쪽 전체를 독립적으로 다시 읽습니다. 의심 표시가 없는 오독은 이 방식으로 찾지 못할 수 있습니다.
- **전체 재판독**: 책 전체를 새로 읽습니다. 현재 OCR·AI·출력 설정을 사용하며 사용량·비용은 실행 전에 안내합니다.
- 기존 폴더를 수정하지 않고 옆에 `재판독-날짜-식별자` 폴더를 만듭니다. `기존작업_보존`에 OCR·교정 이력 사본과 파일 해시를 보관합니다. 선택한 쪽은 기존 답과 캐시를 넘기지 않고 새로 판독합니다. 선택하지 않은 쪽은 기존 기록을 유지해 문서를 구성합니다.
- 새 HWPX 등은 `out`에 저장합니다. `재판독_비교.html`에서 원본 쪽 이미지, 기존 본문, 새 판독을 대조합니다. `재판독_비교.json`과 `재판독_실행.json`에 대상·변경 후보·실행 상태를 남깁니다. 중지·실패 시 기존 자료는 그대로이며 부분 결과를 완료로 표시하지 않습니다.
- 재판독이 끝나면 **현재 결과**에 재판독본이 선택됩니다. **검수·편집 → 재판독 변경 검토·확정**에서 원본 쪽 이미지와 이전·새 판독을 비교하고 변경별로 채택하거나 기존 교정문을 유지합니다. 표·문단 구조가 달라진 쪽은 쪽 단위로 선택합니다.
- **확정 HWPX 만들기**는 선택 내용을 이 책의 출력 양식으로 조립합니다. 새 문서, 판독 기록, 확정 내역은 별도 폴더에 저장됩니다. **현재 결과**에서 이전 버전을 다시 열 수 있습니다.

## 저장과 재사용

- **이 책 설정 → 고급 편집 → 책별 짜임 규칙 관리 ▾**에서 예제나 사용자 JSON을 불러옵니다. 선택한 규칙과 양식은 책마다 저장됩니다.
- **현재 규칙을 별도 파일로 저장…**은 현재 규칙과 양식 경로를 새 JSON으로 저장합니다. 파일 이름과 설명을 책에 맞춰 편집할 수 있습니다.
- **책별 규칙 보관 폴더 열기**로 실제 파일을 찾습니다. Windows 기본 경로는 `%LOCALAPPDATA%\YeonE_OCR\book_rules`입니다. 관리자 권한이 필요한 실행 파일 폴더 대신 프로그램 사용자 자료 폴더를 사용합니다. 업데이트나 프로그램 제거가 이 파일을 지우거나 덮어쓰지 않습니다.
- 처음 메뉴를 열면 두 예시를 만듭니다. 같은 이름의 사용자 파일이 있으면 그대로 둡니다. 사용자 규칙은 실행 코드가 아닌 UTF-8 JSON입니다. 알 수 없는 필드·잘못된 값은 적용 전에 차단합니다.

## ChatGPT와 함께 규칙 만들기

**이 책 설정 → 원본 분석·만들기 → 먼저 분석 결과 보기**를 누르면 PDF 글자층과 책갈피를 로컬에서 훑고 대표 쪽을 고릅니다. 글자층이 없는 쪽은 저해상도 이미지의 모양도 표본 선택에 사용합니다.

대표 쪽을 비우면 최대 8쪽이 자동 선택됩니다. 직접 지정할 때는 `1-3, 20`처럼 최대 12쪽을 적습니다. 구독을 사용하면 대표 이미지를 한 묶음으로 검토하여 제목 단계, 본문·주석·출전, 양식 HWPX 스타일 연결과 목록 배치에 필요한 규칙을 제안합니다. 같은 원본에 해당하는 대표 쪽 OCR과 정렬이 확인된 참고 HWPX 문구만 근거에 포함됩니다. **로컬만**을 고르면 구독 확인과 AI 요청 없이 규칙 초안을 만듭니다.

결과에 분석 범위, 확인한 항목 표지, 양식 스타일 연결과 확인이 필요한 부분을 표시합니다. 입력과 근거가 같은 AI 응답은 재사용합니다. **이 책에 분석 결과 적용**으로 현재 책에 저장합니다. 자동 분석 규칙은 원본 지문으로 연결되므로 다른 PDF에는 새 분석을 실행합니다.

항목 표지는 PDF에서 반복되는 줄 시작 표지와 AI 검토 결과를 사용합니다. 예를 들어 ‘[재료]’와 ‘[주의]’가 확인된 책에는 그 이름으로 문단을 나눕니다. 표지가 없는 문단은 판독 구조와 줄 위치를 따릅니다. 선택한 양식이 있으면 실제 스타일 이름, 글자 크기, 정렬, 줄간격을 비교해 연결을 제안합니다. 양식이 비어 있으면 원본에서 가장 흔한 용지 크기를 사용하고 여백을 추정합니다.

이미지 스캔은 첫 OCR에서 서로 다른 쪽의 문단 시작에 반복되는 괄호 표지를 찾습니다. 같은 원본의 저장 판독을 사용하므로 책마다 다른 항목 이름을 처리할 수 있습니다.

하단 번호 주석은 원본의 쪽 단위로 묶습니다. 각주 뒤에 다음 원본 쪽의 본문이 시작하면 HWPX에 회색 원본 쪽 안내를 붙입니다. 이 주석은 편집 가능한 문단입니다. 한글의 본문 표지와 연결되는 자동 각주 개체는 별도 기능이 필요합니다.

편집용 HWPX에서는 목차와 색인의 행·열, 쪽번호 탭과 점선을 원본 배치에 맞춥니다. 양식에 목록 전용 스타일이 있으면 사용합니다. PDF에서 제목과 대응하는 줄을 찾으면 원본의 정렬·들여쓰기·글자 크기를 반영하고 해당 역할의 양식 스타일 가운데 가장 가까운 후보를 고릅니다. 스캔의 제목 크기는 인쇄된 글자 윤곽으로 추정하며, 원본 근거가 부족하면 양식의 서식을 사용합니다.

기존의 직접 첨부 방식은 자동 생성 창의 **수동 검토 자료…**에서 계속 사용할 수 있습니다.

1. 원본 PDF를 고르고 **이 책 설정 → 원본 분석·만들기 → 수동 검토 자료…**를 누릅니다.
2. 목차·장절 제목·약재·문헌 인용·각주 등을 확인할 수 있는 대표 PDF 쪽을 최대 12쪽 지정합니다. 기존 HWPX를 선택하면 문단 스타일과 대표 문장도 함께 추출합니다.
3. **검토 자료 준비**는 원본 쪽 PNG, HWPX 서식 JSON, 지원 규칙 예시, 요청문 TXT를 사용자 규칙 폴더의 `requests`에 만듭니다. 원본이나 OCR 결과는 수정하지 않습니다.
4. **요청문 복사** 후 이 대화에 붙여넣고 생성된 PNG·JSON을 첨부합니다. **ChatGPT 열기**는 웹사이트를 열고 요청문을 클립보드에 복사합니다. 현재 대화를 자동 선택하거나 파일을 자동 첨부하지 않습니다. 프로그램은 이 과정에서 AI API를 호출하지 않습니다.
5. 검토 결과 JSON을 **고급 편집 → 책별 짜임 규칙 관리 ▾ → 규칙 파일 불러오기…**로 적용합니다. 대표 쪽의 OCR과 출력을 확인하고 전체 OCR을 진행합니다.

## 지원되는 규칙

기존 `entry`, `commentary`, `source`, `emphasis`, `styles`와 함께 다음 선택 필드를 지원합니다.

```json
{
  "schema": 1,
  "id": "my-book",
  "label": "내 책",
  "template": "양식.hwpx",
  "headings": {"chapter": ["綜合論述", "各論"], "section": ["土茯苓"]},
  "citation": {"mode": "separate", "max_title": 80, "continuations": true},
  "styles": {"paragraph": {"citation_source": ["출전"], "quotation": ["인용문"]}}
}
```

`template`의 상대 경로는 규칙 파일이 있는 폴더를 기준으로 합니다. 양식이 없으면 출력 전에 알립니다. 양식 경로가 빈 책별 파일을 선택하면 앞 책의 양식을 가져오지 않습니다. CLI에서도 `--layout flow --preset "규칙.json"`으로 같은 파일을 사용하며 `--template`을 직접 지정하면 그것을 우선합니다.

`headings`는 장·절·소절의 확인된 제목 목록입니다. 간체·번체와 공백·일부 문장기호를 비교용으로만 통일하여 대조하며 OCR 글자 자체는 고치지 않습니다. 제목 등급이 충돌하면 임의로 정하지 않습니다. 일반 본문의 일부 어구만 일치하는 경우는 제목으로 만들지 않습니다.

전체 구조 분석이 끝나면 프로그램은 `page_types`에 유형별 PDF 쪽과 원본 지문을 기록합니다. 출력할 때는 PDF 책갈피, 저장 OCR의 줄과 좌표, PDF 글자층을 함께 대조합니다. 총목의 쪽번호는 오른쪽 탭으로 맞추고 상세 목차는 같은 줄에서 항목을 열별로 배치합니다. 대응이 모호한 항목은 기존 글과 순서를 유지합니다.

중의역대약론선의 `citation`은 `1.《本草綱目》：인용문`을 원래 번호·서명·부호를 가진 출전 문단과 들여쓴 인용 문단으로 나눕니다. 이미 출전이 별도 줄인 경우도 같은 방식으로 처리합니다. 출전은 다음 문단과 함께 배치합니다. 목차 점선·서목 목록은 제외하고, 닫히지 않은 출전은 원문을 유지한 채 검수 빨강으로 표시합니다. 출전 약칭 확장·번호 재생성·각주 복원·다단 목차 자동 작성은 이 규칙의 기능이 아닙니다.
