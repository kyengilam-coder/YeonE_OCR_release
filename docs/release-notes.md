# 연어OCR 0.7.1 · Windows

Windows 10/11 x64에서 Python 설치 없이 실행할 수 있는 설치판입니다.

## 다운로드와 업데이트

- **설치 권장:** `YeonE_OCR-0.7.1-Setup-x64.exe`를 실행합니다. 현재 사용자 계정에 설치하며 시작 메뉴에 연어OCR을 등록합니다. 바탕 화면 바로가기도 선택할 수 있습니다.
- **기존 단일 실행파일 사용자:** `YeonE_OCR-Windows-x64.exe`를 사용합니다. 0.7.0의 자동 업데이트용 파일명과 `update.json` 형식을 유지했습니다.
- OCR 작업을 마치거나 [중지]로 기록을 저장한 뒤 업데이트하십시오. API 키·설정과 문서 옆 OCR 결과 폴더는 유지합니다. 설치판의 [업데이트 확인]은 새 설치파일을 받을 릴리스 페이지로 안내합니다.

## 변경 사항

- Gemini, ChatGPT(OpenAI), Claude(Anthropic) 판독기를 선택하고 제공사별 API 키·모델을 저장합니다.
- 같은 원본·결과 폴더에서 제공사를 바꿔도 완료한 쪽과 저장된 판독을 이어 사용합니다.
- 최종 HWPX·DOCX를 간체에서 번체로 교정하고, 지정한 MSR의 치환 후보는 원문 문맥으로 판단합니다. 云/雲도 문맥으로 선택합니다.
- 확정할 수 없는 문맥 교정은 원문을 보존하고 `*_normalization.html`에 확인 대상으로 남깁니다.
- 작은 크기에서도 잘 보이는 아이콘을 적용했습니다.
- 기존 배포판의 원본·영상 설정 검증, 중지·재시도, 자동 업데이트와 오류 수정도 유지했습니다. 원본 지문이 없거나 입력이 바뀐 옛 작업은 `archives/`에 보관하고 새로 처리하므로, 실행 전 비용 미리보기를 확인하십시오.

각 제공사의 API 키와 이용 권한이 필요하며 API 이용료는 별도입니다. 실행파일·설치파일에는 개인 API 키, 사용자 설정, 원본 문서나 OCR 작업 기록을 넣지 않았습니다.

## 검증과 구성

- 앱 자동 테스트 576개와 하위 테스트 91개, 릴리스 자료 검사 6개 통과.
- 설치용 실행파일과 단일 실행파일에서 각각 오프라인 검사 19개 통과: SDK·변환 사전·아이콘·Tk 및 합성 PDF→HWPX/DOCX 생성·재열기.
- 설치파일로 설치·재설치·제거를 확인했으며, 설치된 앱의 19개 검사와 설치 폴더 밖 시험 자료 보존 검사도 통과했습니다.
- 실제 유료 OCR 호출과 실제 문서의 인식 정확도 평가는 이번 배포 검사에 포함하지 않았습니다.
- 동일 버전의 소스, 빌드 스크립트, 외부 구성 요소 고지·라이선스와 SHA-256 목록을 함께 제공합니다.
- 설치파일과 실행파일은 코드 서명되지 않았습니다.
