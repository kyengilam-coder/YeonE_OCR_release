Windows에서 Python 설치 없이 실행할 수 있는 첫 단독 실행 판입니다.

- `YeonE_OCR-Windows-x64.exe`를 내려받아 쓰기 가능한 폴더에 두고 실행하십시오.
- 시작할 때 새 정식 버전을 자동 확인합니다. 새 버전이 있으면 설치 후 재시작하거나 나중에 설치할 수 있습니다.
- OCR 작업 중에는 설치하지 않습니다. 다운로드 크기와 SHA-256을 확인한 뒤 프로그램을 교체하며, 교체 실패 시 이전 실행 파일을 보존합니다.
- API 키와 사용자 설정, 문서·OCR 결과는 실행 파일 업데이트와 별도로 보존됩니다.
- 0.6.9의 원본 캐시 검증, PDF 영상 보존, 교정 오류 방지 및 재시도 개선을 포함합니다.

실제 Gemini OCR에는 사용자의 API 키가 필요합니다. 비교용 OCR 벤치마크는 이번 배포에서 실행하지 않았습니다.

이전 버전의 원본 지문 없는 작업 기록은 실제 처리 시 `archives/`에 보관하고 다시 판독합니다. 다시 판독하는 분량은 비용 미리보기에 반영됩니다.

소스는 이 릴리스의 source ZIP과 저장소에서 확인할 수 있습니다. `update.json`은 프로그램의 자동 업데이트용 파일이며 직접 실행할 필요가 없습니다.
