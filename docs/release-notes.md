# 연어OCR 0.7.2 · Windows

Windows 10/11 x64에서 Python 설치 없이 실행할 수 있는 설치판입니다.

## 스크린샷으로 시작하기

1. `Win+Shift+S`로 읽을 글이 있는 부분을 캡처합니다.
2. 연어OCR에서 **[스크린샷 붙여넣기]** 또는 `Ctrl+Shift+V`를 누릅니다.
3. **[원본 보기]**로 확인한 뒤 **[▶ 한 번에 인식 (PDF·이미지 → HWPX)]**을 누릅니다.

기존 PNG·JPG 등 이미지 파일도 **[PDF·이미지 고르기…]**에서 계속 사용할 수 있습니다. Gemini·ChatGPT(OpenAI)·Claude(Anthropic) 중 원하는 제공사를 선택합니다. 붙여넣기만으로 API를 호출하지 않으며, 직접 인식을 실행할 때 비용 미리보기를 확인합니다.

가로쓰기 캡처는 실행 전에 **[읽기 방향]**을 가로쓰기로 고르십시오. 이미지의 자동 방향 판정은 세로쓰기를 기본으로 사용합니다. 붙여넣어도 선택한 읽기 방향은 유지합니다.

## 변경 사항

- 클립보드 이미지를 원래 해상도의 RGB PNG로 `%LOCALAPPDATA%\YeonE_OCR\screenshots`에 보관합니다.
- 같은 픽셀의 캡처를 다시 붙이면 같은 원본과 기존 판독 기록을 이어 씁니다. 제공사나 모델을 바꾼 뒤에도 저장된 판독을 재사용합니다.
- 다른 캡처는 별도 원본·기록을 사용합니다. 저장된 원본이 나중에 수정되었으면 그 파일을 보존하고 새 파일을 만듭니다.
- 붙여넣을 때 쪽 범위와 인쇄 쪽수 차이를 비우고 "기록 있는 쪽도 다시 판독"을 끕니다. 제공사·모델·읽기 방향은 유지합니다.
- 선택한 PDF·이미지를 여는 **[원본 보기]**와 이미지 입력을 명시한 인식 버튼을 제공합니다.
- 0.7.1의 세 제공사 선택, 중단 작업 이어 읽기, 최종 HWPX·DOCX의 번체·MSR·云/雲 문맥 교정을 유지합니다.

각 제공사의 API 키와 이용 권한이 필요하며 API 이용료는 별도입니다. ChatGPT·Claude 웹 구독과 API는 별개입니다.

## 다운로드와 업데이트

- **설치 권장:** `YeonE_OCR-0.7.2-Setup-x64.exe`를 실행합니다. 현재 사용자 계정에 설치하며 시작 메뉴에 연어OCR을 등록합니다. 바탕 화면 바로가기도 선택할 수 있습니다.
- **단일 실행파일 사용자:** `YeonE_OCR-Windows-x64.exe`를 사용합니다. 기존 자동 업데이트용 파일명과 `update.json` 형식을 유지합니다.
- OCR 작업을 마치거나 [중지]로 기록을 저장한 뒤 업데이트하십시오. API 키·설정, 원본 옆 OCR 결과 폴더, 저장한 스크린샷을 유지합니다. 설치판의 [업데이트 확인]은 새 설치파일을 받을 릴리스 페이지로 안내합니다.

## 검증과 구성

- 전체 자동 테스트 607개와 하위 테스트 103개 통과. 스크린샷 저장·중복 재사용·기존 파일 보존·화면 설정 초기화 및 모의 판독 PNG→HWPX 본문 검사를 포함합니다.
- 소스 실행, 설치용 실행파일, 단일 실행파일에서 각각 오프라인 검사 20개 통과. Windows 클립보드 기능의 포함 여부와 원본 해상도 보존·PNG 입력·문서 생성을 확인했습니다.
- 100% 화면 배율의 1180×980 및 960×640 창에서 새 입력 행과 실행 버튼이 잘리지 않는 것을 확인했습니다.
- 이번 판의 설치·재설치·제거는 현재 PC의 기존 설치를 보호하기 위해 재실행하지 않았습니다. 0.7.1에서 검증한 설치 구조를 유지합니다.

실제 사용자 클립보드와 유료 OCR API는 사용하지 않았으며, 실제 캡처의 인식 정확도는 이번 검사 범위에 포함하지 않았습니다. 배포 자료에는 같은 버전의 소스·빌드 스크립트, 외부 구성 요소 고지·라이선스와 SHA-256 목록을 포함하며, 개인 API 키·설정·원본 문서·스크린샷·OCR 기록을 넣지 않습니다. 설치파일과 실행파일은 코드 서명되지 않았습니다.
