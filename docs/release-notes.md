# 연어OCR 0.7.3 · Windows

Windows 10/11 x64에서 Python 설치 없이 실행할 수 있는 설치판입니다.

## 작업과 설정을 네 탭으로 분리

**[일반 OCR]·[책갈피 OCR]·[이미지(스크린샷) OCR]·[설정]**으로 나눴습니다. PDF는 [일반 OCR]의 **[PDF 고르기…]**에서, 이미지와 캡처는 세 번째 탭에서 선택합니다. 세 작업 탭은 각 원본을 유지하며 쪽 범위·인쇄 쪽수 보정과 실행·결과 열기를 제공합니다.

판독기·모델·API 키·읽기 방향·세부 옵션·문서 설정은 네 번째 **[설정]**에 모았습니다. 책갈피 교정 정책·메모·재판독과 고급 도구도 이곳에 있습니다. 작업 탭에서 현재 판독기·모델·읽기 방향 요약 옆의 **[설정 바꾸기]**를 누르고, 설정 아래의 **[설정 저장]·[OCR로 돌아가기]**로 저장과 복귀를 할 수 있습니다.

## 이미지·스크린샷 전용 탭

1. 세 번째 **[이미지(스크린샷) OCR]** 탭을 엽니다.
2. **[이미지 고르기…]**로 PNG·JPG 등을 선택하거나, `Win+Shift+S`로 캡처한 뒤 **[스크린샷 붙여넣기]** 또는 `Ctrl+Shift+V`를 누릅니다.
3. 옆의 **[원본 보기]**로 확인한 뒤 **[한 번에 인식]**을 누릅니다.
4. 끝나면 **[HWPX 바로 열기]**로 결과를 엽니다. **[저장 폴더]**는 HWPX가 들어 있는 `out` 폴더를 엽니다.

이미지 원본 선택은 [일반 OCR]·[책갈피 OCR]과 독립적으로 유지합니다. 제공사·API 키·모델과 문서 설정은 공유하므로 Gemini·ChatGPT(OpenAI)·Claude(Anthropic) 중 고른 설정으로 처리합니다. 붙여넣기만으로 API를 호출하지 않으며, 직접 인식을 실행할 때 비용 미리보기를 확인합니다.

이미지 탭의 **HWPX 저장** 줄에는 드라이브부터 시작하는 전체 경로가 표시됩니다. 캡처의 기본 결과 경로는 `%LOCALAPPDATA%\YeonE_OCR\screenshots\screenshot-<hash>_png_YeonE_OCR\out\screenshot-<hash>.hwpx`입니다. `<hash>`는 캡처마다 달라지며 0.7.2의 원본·판독 기록·결과 위치를 그대로 사용합니다.

가로쓰기 캡처는 실행 전에 **[설정 바꾸기]**를 눌러 [설정]의 **[읽기 방향]**을 가로쓰기로 고르십시오. 이미지의 자동 방향 판정은 세로쓰기를 기본으로 사용합니다. 붙여넣어도 선택한 읽기 방향은 유지합니다.

## 변경 사항

- 이미지·캡처를 위한 세 번째 탭을 추가하고 **[이미지 고르기…]·[스크린샷 붙여넣기]·[원본 보기]**를 가까이 배치했습니다.
- 네 번째 **[설정]**으로 공통 옵션과 고급 도구를 모으고, 작업 탭에 설정 요약·**[설정 바꾸기]**, 설정 아래에 **[설정 저장]·[OCR로 돌아가기]**를 배치했습니다.
- HWPX 저장 위치를 전체 경로로 표시하고 **[HWPX 바로 열기]·[저장 폴더]**를 한 번에 누를 수 있게 했습니다.
- 다른 탭의 원본 선택을 바꾸지 않고 이미지를 처리하며 API·모델·문서 설정은 함께 사용합니다.
- 기존 캡처의 RGB PNG 저장, 같은 픽셀의 원본·판독 기록 재사용, 변경된 저장 파일 보존을 유지합니다.
- 세 제공사 선택, 중단 작업 이어 읽기, 최종 HWPX·DOCX의 번체·MSR·云/雲 문맥 교정을 유지합니다.

각 제공사의 API 키와 이용 권한이 필요하며 API 이용료는 별도입니다. ChatGPT·Claude 웹 구독과 API는 별개입니다.

## 다운로드와 업데이트

- **설치 권장:** `YeonE_OCR-0.7.3-Setup-x64.exe`를 실행합니다. 현재 사용자 계정에 설치하며 시작 메뉴에 연어OCR을 등록합니다. 바탕 화면 바로가기도 선택할 수 있습니다.
- **단일 실행파일 사용자:** `YeonE_OCR-Windows-x64.exe`를 사용합니다. 기존 자동 업데이트용 파일명과 `update.json` 형식을 유지합니다.
- OCR 작업을 마치거나 [중지]로 기록을 저장한 뒤 업데이트하십시오. API 키·설정, 원본 옆 OCR 결과 폴더, 저장한 스크린샷을 유지합니다. 설치판의 [업데이트 확인]은 새 설치파일을 받을 릴리스 페이지로 안내합니다.

## 검증과 구성

- 전체 자동 테스트 실행에서 **637개와 하위 테스트 119개 통과**, Tcl 환경 관련 검사 **1개 건너뜀**. 이 1개(`tests/test_ops.py:728`)는 소스를 바꾸지 않고 `TCL_LIBRARY`·`TK_LIBRARY` 경로를 명시한 별도 실행에서 통과하여 총 638개 항목을 확인했습니다. 작업 탭의 독립 입력, 설정 이동·저장·복귀, 공통 설정 공유, 저장 경로 표시와 결과 열기 등을 검사했습니다.
- 전체 `yeone_ocr`·`tests`·`tools`·`scripts`의 Ruff `E9,F63,F7,F82` 검사와 변경한 GUI·테스트 파일의 `E9,F` 검사를 통과했습니다.
- 소스 실행·설치용 실행파일·단일 실행파일에서 **오프라인 검사 각각 20개 통과**. 두 실행파일의 앱 모듈 **각각 48개**가 최신 소스와 일치하며, 동봉 README·고지문과 라이선스 참조 **162개**도 원본과 일치했습니다.
- 100% 화면 배율의 **1180×980·960×640** Tk 창에서 버튼이 잘리지 않는 것을 확인했습니다.
- 커밋 `a0d9e02`의 원격 CI가 통과했습니다.
- Windows 설치파일 빌드를 완료했습니다.

이번 판에서는 현재 PC의 기존 설치를 보존하기 위해 설치·재설치·제거 검증을 다시 실행하지 않았습니다. 0.7.1에서 검증한 설치 구조를 사용합니다.

실제 유료 OCR API와 실제 캡처의 인식 정확도는 이번 검사 범위에 포함하지 않았습니다. 배포 자료에는 같은 버전의 소스·빌드 스크립트, 외부 구성 요소 고지·라이선스와 SHA-256 목록을 포함하며, 개인 API 키·설정·원본 문서·스크린샷·OCR 기록을 넣지 않습니다. 설치파일과 실행파일은 코드 서명되지 않았습니다.
