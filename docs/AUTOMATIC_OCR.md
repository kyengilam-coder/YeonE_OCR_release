# 쪽별 자동 엔진 선택 · 0.11.0

상단 **자동 로컬 OCR·비교**에서 원본·문서 종류·읽기 방향을 선택하고 현재 쪽 또는 지정 범위를 실행한다. 자동 선택이 기본으로 켜진다. 체크를 끄면 엔진을 직접 고를 수 있다. 이 기능은 로컬 OCR에 적용하며 유료 AI 호출을 실행하지 않는다.

설치된 PP-OCRv6는 기존에 저장한 엔진 폴더와 독립적으로 찾는다. 다른 엔진은 기존 폴더를 사용한다. 명시한 폴더가 없을 때는 각 엔진의 프로그램 폴더·사용자 설치 폴더를 따로 탐색한다. 내장 v6가 손상됐을 때 같은 엔진의 다른 사본으로 몰래 바꾸지 않고 설치 오류를 기록한다.

문서 종류에 맞는 언어 모델이 있는 엔진만 실행한다. 간체·번체는 PP-OCRv6·PP-OCRv5·EasyOCR·Tesseract를 비교할 수 있다. 한글·한자 혼용은 두 문자 체계를 지원하는 Tesseract를 사용한다. 한국어 신경망 모델의 한자 누락을 정상 판독으로 취급하지 않는다. 지원되는 엔진이 없으면 필요한 모델이 없음을 표시한다.

엔진은 한 번에 하나씩 실행한다. 깨진 문자, 지원 문자 비율, 판독 길이의 중앙값 대비 누락 정도, 다른 엔진과의 문자 일치도, 같은 위치의 중복 검출을 합산해 **한 쪽의 원문 하나**를 선택한다. 엔진별 confidence를 서로 비교하거나 글자를 섞어 새 원문을 만들지 않는다. 동점이면 PP-OCRv6 → PP-OCRv5 → EasyOCR → Tesseract 순서다. 고정 답안·테스트 정답·특정 글자 치환표를 선택 근거로 사용하지 않는다.

이는 정답 없이 계산한 품질 추정이며 실제 인식률이나 항상 가장 정확한 엔진이라는 보장은 아니다. 엔진들이 불일치하거나 단일 엔진만 읽을 수 있으면 원본 대조 표시를 남긴다. 확인 표시가 있어도 일괄 OCR은 계속 진행한다. 기존 직접 교정, 사람이 고른 기준 판독, 검수한 기준은 자동 선택으로 덮어쓰지 않는다.

프로젝트의 `auto_selections`에 선택 정책, 비교한 실행 ID, 점수별 근거, 제외된 엔진과 사유, 선택·적용 여부를 저장한다. 각 실행에는 실제 사용한 엔진 폴더·모델 해시를 기록한다. 실패한 엔진의 이전 결과를 이번 선택에 포함하지 않는다. 중지하면 완료한 원시 결과만 보관하고 자동 선택은 적용하지 않는다.

Windows는 물리 RAM이 남아 있어도 커밋 한도가 부족할 수 있다. 자동 모드는 물리 RAM과 커밋 여유를 확인한다. 운영상 여유 기준은 PP-OCRv6·v5 640MiB, EasyOCR 2GiB, Tesseract 128MiB이며 모델의 공식 최소 사양이나 최대 사용량을 뜻하지 않는다. 부족한 엔진은 이번 작업에서 제외하고 사유를 기록한다. 실행 중 다른 프로그램이 메모리를 사용할 때 발생하는 실패도 보존하고 성공한 엔진의 결과로 계속한다.

명령줄은 `compare-engines`의 기본값이 자동 선택이다. `--auto-engine`으로 명시하거나 `--engines ppocrv6 easyocr`로 직접 비교를 선택할 수 있다. 원본이나 사용자 설정·자료를 바꾸거나 모델을 자동 다운로드하지 않는다.
