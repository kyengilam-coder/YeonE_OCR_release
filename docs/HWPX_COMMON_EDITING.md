# HWPX 공통 편집 기준 (1.2.25 기본값)

1. **본문만 수록**: 원본 머리말·꼬리말·쪽번호·판심·좌우 여백 장식글과 작업용 책갈피를 제외한다. 실제 제목·원문 주석·소주와 목차 본문의 참조 쪽수는 유지한다.
2. **제목 가운데 맞춤**: 확인된 책·권·장·절·소절 제목을 가운데 맞춘다. 본문·약재명은 제목으로 추측해 바꾸지 않는다.
3. **새 쪽 시작**: 책·권·장 제목 앞에서만 새 쪽을 시작한다. 절·소절 제목은 같은 쪽에서 이어 쓴다. 문서 첫 제목 앞에는 빈 쪽을 만들지 않는다.
4. **제목 고립 방지**: 제목과 다음 본문이 따로 떨어지지 않게 한다. 사이에 빈 문단이 있으면 함께 이어 두되, 긴 본문 전체를 한 쪽에 강제로 묶지 않는다.
5. **본문 흐름**: 문단 내부 인쇄 줄은 이어서 자동 줄바꿈한다. 본문 외톨이줄 보호를 켠다. 약재 사이 빈 줄 하나, 약재명 뒤 공백 하나, 쉼표 뒤 공백 하나를 유지한다. 숫자 쉼표와 의심 판독 표시는 보존한다.
6. **확인 필요 글자는 본문에서 빨강**: 기존 판독 의심 표시와 함께, 한자 변환이 미확정인 글자·어구도 빨간 글자색으로 표시한다. 변환 보류를 표시하기 위해 본문에 설명·대괄호·작업 메모를 새로 넣지 않는다. 제목과 표 안에서도 표시한다.
7. **색의 의미**: 빨강은 확인이 필요하다는 뜻이며, 오인식이 확정됐다는 뜻은 아니다. 색이 없다는 것만으로 모든 판독이 정확함을 보증하지 않는다. 원래 검증 등급과 교정 이력은 보존한다.
8. **확실한 근거로만 자동 처리**: 구조화 판독의 제목 등급, 독립된 책·권·장·절 표기, 표제지 문맥, 실제 측정된 배치를 사용한다. 쪽 전체로 표시된 거친 좌표만 보고 가운데 맞춤하지 않는다. 단지 문맥이 달라 보인다는 이유로 새 장이나 쪽 나눔을 만들지 않는다. 불확실한 제목 등급은 검토 대상으로 남긴다.
9. **서식으로 구현**: 가운데 배치를 여러 공백으로 흉내 내거나 새 쪽을 엔터 반복으로 만들지 않는다. 한글의 문단 정렬·쪽 나눔·다음 문단과 함께·외톨이줄 속성을 사용한다.
10. **출력만 편집**: 최신 교정문을 사용하되 원시 OCR, 사람 교정, 완료 AI 검증을 덮어쓰지 않는다. 검색 가능한 문자 PDF는 원본 이미지와 판독·교정 글자를 유지하고 HWPX 편집용 한자·서식 규칙을 적용하지 않는다.

`--no-common-layout`은 공통 정렬·쪽 나눔만 끈다. `--no-highlight`는 검수 색상을 끈 검정색 출력용이다. 기본값은 공통 편집과 검수 색상 모두 켜짐이다. `--no-document-editing`은 기존 방식의 문단 편집을 선택할 때 사용한다.

서식은 한컴의 문단 기능을 사용한다. [문단 모양: 확장](https://help.hancom.com/docs/ko-KR/mergedProjects/hoffice_hwp/topics/hancomoffice/hwp/format/paragraph/paragraph_expanded.htm), [문단 정렬 방식](https://help.hancom.com/docs/ko-KR/mergedProjects/hoffice_hwp/topics/hancomoffice/hwp/format/paragraph/paragraph%28alignment%29.htm).
