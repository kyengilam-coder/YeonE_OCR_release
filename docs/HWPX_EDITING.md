# HWPX 기본 편집 (1.2.24)

**본문만 수록합니다.** 머리말·꼬리말·인쇄 쪽번호·판심·좌우 여백의 장식글·작업용 책갈피는 HWPX에 넣지 않습니다. 본문에 속한 실제 장절 제목과 원문 주석은 유지합니다. 이 원칙은 패키지의 `지침.md` 16절과 요약 지침에도 명시되어 있습니다.

HWPX를 만들 때 현재 교정문을 우선하고, 원본 판독 기록과 교정·AI 검증 이력은 저장하거나 덮어쓰지 않습니다. 문자 PDF의 글자는 원문 판독·교정 결과를 유지합니다. HWPX의 한자·부호 변환은 출력 사본에만 적용합니다.

- 로컬 판독의 인쇄 줄을 문단으로 잇고, 문단 내부의 강제 줄바꿈을 제거합니다. 아래한글이 용지 폭에 맞춰 자동 줄바꿈합니다. 원본의 빈 줄과 확인된 약재 시작으로 문단을 구분합니다.
- 약재 시작 앞에는 빈 문단 하나를 넣습니다. 약재 제목과 바로 이어지는 본문은 한 문단으로 합칩니다.
- 약재명 뒤 공백 하나, 쉼표 뒤 공백 하나를 사용합니다. 숫자의 `1,000`, 의심 표시 안의 텍스트는 유지합니다. 약재명은 원본의 이름·본문 간 공백과 문서에서 확인된 이름을 근거로 인식합니다. 확인되지 않는 이름을 추측해 분리하지 않습니다.
- 기본 간체→번체, 한국 표준 한자체(爲·眞·靑 등), 중문부호 규칙을 적용합니다. 간체 전용 글자는 OpenCC의 문맥 사전으로 번체화합니다. 干·后 등 원래도 쓰이는 한자가 여러 뜻으로 갈리면 기존 문맥 검증과 보고를 유지합니다. 모든 이체자를 일률 치환하지 않습니다.
- 기본 문서는 Source Han Serif K Medium(본명조 Medium)을 사용합니다. 사용자 양식을 선택하면 양식의 글꼴을 따릅니다.
- 본문에 원본 쪽 연결 책갈피와 작업 기록 줄을 넣지 않습니다. 판독에서 분류한 머리말·쪽번호, 여백에서 위치·반복·쪽번호로 확인한 머리말/꼬리말도 출력에서 제외하고 변환 보고서에 기록합니다. 목차 항목·책의 본래 제목·본문 속 책 이름은 유지합니다. 위치 근거가 없는 줄은 추측해 삭제하지 않습니다.

명령줄에서 `--no-document-editing`으로 문단·공백 편집을 끌 수 있습니다. 한자·부호 변환은 별도 `--no-traditional`, `--no-korean-forms`, `--no-punctuation`, `--no-normalize` 옵션으로 제어합니다. `--no-context-model`은 외부 AI 없이 사전·규칙 변환만 수행하고 불명확한 후보를 변환 보고서에 남깁니다. 문단 정리 자체는 AI를 호출하지 않습니다.
