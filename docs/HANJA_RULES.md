# 한자 변환 규칙

설정 → 자동 교정 → **한자 변환 규칙 → 규칙 추가·수정…**에서 편집합니다.
검색, 추가, 수정, 삭제, 순서 변경 후 **파일로 저장하고 적용…**을 누르면
선택한 JSON 파일의 경로를 설정에 저장하여 다음 실행에도 재사용합니다.
**파일에서 고르기…**로 저장한 규칙을 선택하고 **기본 규칙**으로 내장 규칙을 복원합니다.

- **자동 치환**: 찾을 글자가 일치하면 문서에서 바로 바꿉니다. 긴 문자열도 지원합니다.
- **문맥 확인**: 뜻이 달라질 수 있는 치환을 후보로 남깁니다. 예를 들어 `術→朮`을 자동으로 지정하면 `醫術`도 `醫朮`로 바뀌므로 용도에 맞게 선택합니다.
- **문맥 자동(叶→葉)**: 편집형 간체→번체 출력에서 잎을 뜻하는 `叶`를 `葉`로 바꾸되 `叶韻` 같은 표기는 보존합니다.
- **문맥 자동(于→於·이름 보존)**: `取決于膽`, `專于利水`, `無逾于此` 같은 문법 용례를 바꾸고 `于謙`, `于右任`, `淳于`, `鮮于`, `于闐`, 책 이름 등은 보존합니다. 이름인지 판단하기 어려운 용례는 일괄 치환하지 않고 문맥 확인 후보로 남깁니다. 사용자 규칙 목록에서 이 항목을 삭제하면 자동 적용하지 않습니다.

내장 규칙은 한국 표준 자형과 제공된 260929 MSR의 한자 치환을 합치고 중복·동일 치환을 정리한 목록입니다.
MSR 가져오기는 치환 문자열만 읽으며 매크로를 실행하지 않습니다. 부호 치환은 기존 **중문부호 규칙**에서 편집합니다.

저장한 사용자 목록은 내장 한자 목록에 덧붙이는 방식이 아니라 **대체하는 목록**입니다.
목록에서 삭제한 자형 치환을 숨은 기본 규칙으로 다시 적용하지 않습니다.
다만 **간체→번체** 사전 변환은 별도의 옵션이므로, 한자 규칙 삭제가 그 사전 전체를 끄지는 않습니다.
자동 한자 규칙은 **한국 표준 한자체**가 켜져 있을 때, 문맥 후보는 **간체→번체**가 켜져 있을 때 사용합니다.

규칙은 출력 HWPX·DOCX에만 적용합니다. 원시 OCR, 교정·AI 검증 이력, 문자 PDF는 변경하지 않습니다.
사용자 규칙 저장은 기존 OCR 프로젝트·설정 파일을 덮어쓰지 못하도록 기존 규칙 JSON인지 검사합니다.

```json
{
  "schema_version": 1,
  "rules": [
    {"find": "產", "replace": "産", "mode": "auto"},
    {"find": "叶", "replace": "葉", "mode": "leaf"},
    {"find": "術", "replace": "朮", "mode": "review"}
  ]
}
```

명령줄에서는 `--hanja-rules 규칙.json`을 지정합니다. 비어 있는 사용자 목록은 자동 한자 치환을 비우는 것이며,
내장 목록으로 돌아가려면 GUI의 **기본 규칙**을 누르거나 명령줄의 `--hanja-rules`를 생략합니다.

책별 양식은 **설정 → 이 책 → 양식 스타일 → 스타일 설정…**에서 연결합니다. 원본 HWPX를 고른 뒤 책·권·장 제목, 약재·절 제목, 소분류 제목, 본문, 출전, 인용문 등의 스타일을 선택해 책별 규칙 JSON으로 저장하십시오. 글꼴·크기·기본 색상은 원본 스타일을 재사용하며, 검수 색상은 별도로 유지합니다. 소분류 제목은 양식에서 확인한 상위 약재 아래에서만 적용하고 새 쪽을 강제하지 않습니다.

기본 서적명 규칙은 `本草征要 → 本草徵要`입니다. `征` 자체를 일괄 치환하지 않으며,
설정의 한자 규칙 목록에서 이 어구를 수정·삭제할 수 있습니다.

HWPX 편집 시 `元素 曰 : 原文`은 `元素曰: 原文`으로, 별도 출전 제목 줄의
`12.『本草新編』 : `는 `12.『本草新編』`으로 정리합니다. 본문 뒤의 `【注】`·`【註】`는
새 문단에서 시작하고, 그 안의 `[1]`·`[2]` 설명을 각각 문단으로 나눕니다.
검수 색상·메모는 나뉜 글자 위치로 옮깁니다. 일반 본문의 대괄호 숫자는 이 규칙으로 나누지 않습니다.
사용자 양식을 지정한 본문·인용문은 원본 스타일의 줄 나눔·정렬·간격을 그대로 사용합니다.

출전 제목 줄의 `『綱目』`은 `『本草綱目』`으로 통일합니다. 본문 속 약칭은 유지합니다.
`咸→鹹`은 `味咸`, `甘咸溫潤`, `咸能軟堅`처럼 맛을 뜻하는 문맥이 분명할 때만 적용합니다.
`咸陽` 등의 지명·이름은 보존하며, 불확실한 용례는 기존 문맥 검수 대상으로 남깁니다.

`炮制 → 炮製`도 기본 어구 규칙으로 적용합니다. `制` 한 글자를 일괄 치환하지 않습니다.
약재명 `干姜·干薑→乾薑`도 기본 어구 규칙입니다. 성씨 `姜`의 일괄 치환은 하지 않습니다.
사용자가 지정한 `髒→臟`은 모든 용례를 정리하는 기본 자동 치환 규칙입니다. 기존 문맥 확인 후보보다 이 선택을 우선합니다.
뜻에 따라 다른 글자를 고르는 규칙은 편집 창의 **문맥 판별 규칙** 분류에 모두 모읍니다.
`云/雲`, `松/鬆`, `干/乾/幹`, `着/著`, `极/極`, `于/於`, `咸/鹹`, `叶/葉` 전용 규칙과
기존 `術/朮`, `后/後` 등 **문맥 확인** 후보가 이 분류에 포함됩니다. **자동 치환 규칙**은 별도로 볼 수 있습니다.
분류는 전체 규칙의 보기이며 문맥 규칙만 저장하여 다른 규칙을 잃지 않습니다. 저장 시 전체 목록을 보존합니다.

`松/鬆`은 `根中虛松竅大者`, `其體极松`, `質地疏松`처럼 조직·성상이 성긴 뜻이면 `鬆`,
`松樹·松脂·松柏` 같은 소나무·약재 어휘는 `松`을 보존합니다. 특정 구절 하나에만 적용되는 치환이 아닙니다.
`干/乾/幹`은 `咽干→咽乾`의 목마름·건조, `成根荄枝干→成根荄枝幹`의 줄기, `干戈·干涉`의 보존을 구분합니다.
`着/著`은 `着作→著作`의 저술·드러남과 `着衣·附着` 등의 입음·붙음을 구분합니다.
`极/極`은 `此藥質极黏膩→此藥質極黏膩`, `其體极松→其體極鬆`처럼 정도가 매우 심하다는 문맥을 구분합니다.
`胜/勝`은 `土旺則能胜溼→土旺則能勝濕`처럼 제어·극복·감당의 뜻을 구분합니다.
`溼→濕`은 문맥과 관계없이 적용하는 편집 가능한 기본 자형 통일 규칙으로 자동 치환 분류에 둡니다.
확실한 어휘·성상 구문은 출력에서 정리하고, 근거가 겹치거나 부족하면 云/雲과 같은 기존 전체 문맥 판별기로 보냅니다.
문맥 판별을 끄거나 답을 확정하지 못하면 원문을 유지하고 검수 대상으로 남깁니다. 새 구독·API 호출을 임의로 추가하지 않습니다.

**설정 → 이 책 → 于/於 표기 기준**은 고전 문헌(기본), 1900년 이후 출판물, 현대 중국 백화문으로 구분합니다.
기본 고전 규칙은 일반 문장의 于→於와 이름 보존을 적용합니다. 뒤의 두 기준은 于를 보존하며 단자 자동 치환보다 우선합니다.
출판 연도나 문체는 파일 이름에서 추정하지 않고 사용자가 책별로 지정합니다. 원래의 於를 于로 역변환하지는 않습니다.
CLI는 `--yu-policy classical|post1900|vernacular`로 지정합니다.

검수 표시 기본값: 공백에는 검수 배경색을 붙이지 않고 문장부호에 빨간 검수 색상이나 노란 배경을 붙이지 않습니다.
폭·공백 차이만 있는 쉼표는 기존 엔진 후보를 대조해 출력에서 검수 색상을 제외합니다.
의심 한자·확정 한자의 검수 색상과 원본 양식의 글꼴은 유지합니다.
원시 OCR·교정·AI 응답·판정 기록은 변경하지 않으며 기존 기록으로 재출력할 때도 적용합니다.

본문의 중간 생략 기호는 앞뒤 공백을 둔 ` … `로 통일합니다. `……`, `......`, `⋯⋯` 등은 하나로 줄입니다.
목차의 항목·쪽번호 연결 점선과 판독 표시 괄호 안의 원문은 보존합니다. 중문부호 정리를 끄면 적용하지 않습니다.

한 글자씩 띄어 읽은 OCR 문단은 단일 한자 토큰 비율 65% 이상·한자 토큰 12개 이상·한자 사이 공백 8곳 이상의 근거가 있을 때 정리합니다.
제목·출전 제목은 구조가 확인된 경우 내부 한자 공백을 정리합니다. 한국어가 섞인 문단과 일반적인 어구별 띄어쓰기는 유지합니다.
정리 후에도 한자 검수 범위·메모는 같은 글자로 옮깁니다.

완료 AI 판독의 확실한 대응 구간은 로컬 불일치만으로 다시 노랗게 덮지 않습니다.
저장 응답과 당시 결과·검증 요약을 정확히 재현한 근거가 있는 기존 빨간 글자는 배경 없는 파랑으로 구분합니다.
사람 교정·판정, AI가 직접 의심한 글자, 별도 AI 구간 제안과 대응 불명 장문은 보호합니다.
