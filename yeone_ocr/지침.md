# 세로쓰기 한자·한글 혼용 문헌 OCR·교정 프로젝트 지침

## 1. 프로젝트 목적

이 프로젝트는 한자와 한글이 혼용된 세로쓰기 문헌을 원본 이미지와 대조하여 정확한 편집용 문서로 복원하는 것을 목적으로 한다.

대상 자료는 고서·역학서·풍수지리서·한의학서·족보·문집·전통 학술서적 등의 스캔 PDF, 이미지 및 기존 OCR 자료이다.

다음 요소를 구분하여 각각 적합한 방식으로 처리한다.

1) 일반 본문
2) 제목·장절명
3) 주석·소주
4) 표
5) 원형 도표
6) 방위도·나경도
7) 산형도·지형도·삽화
8) 계통도·연결도
9) 숫자·괘상·기호
10) 쪽번호·머리말·꼬리말

OCR의 목적은 문맥상 그럴듯한 문장을 만드는 것이 아니라 원본에 실제로 인쇄된 문자와 도형 구조를 최대한 정확하게 복원하는 것이다.


## 2. 가장 중요한 기본 원칙

판독의 기준은 원본 이미지에 실제로 보이는 자형과 배열이다.

판정 우선순위는 다음과 같다.

원본 이미지의 실제 자형 및 배치 > 원본에서 확인한 읽기 순서 > 앞뒤 문맥 > 전문용어 > 기존 OCR 텍스트

기존 OCR 텍스트가 있더라도 정답으로 간주하지 않는다.

특히 다음 오류를 주의한다.

- 한자가 한글 또는 한글 자모로 바뀜.
- 한글이 한자로 바뀜.
- 숫자가 영문자로 바뀜.
- 괘상이 일반 문자나 특수기호로 바뀜.
- 작은 한자가 점·선·숫자로 바뀜.
- 한자 부수가 별도 문자로 분리됨.
- 세로쓰기 열 순서가 뒤섞임.
- 오른쪽 열과 왼쪽 열의 문장이 교차 결합됨.
- 그림 내부 문자와 본문 문자가 섞임.

문장이 자연스럽다는 이유만으로 판독이 정확하다고 판단하지 않는다.


## 3. 작업 시작 전 페이지와 영역을 분류한다

각 페이지를 먼저 살펴보고 아래 유형을 판정한다.

한 페이지에 여러 유형이 있으면 페이지 전체를 하나의 유형으로 처리하지 말고 영역별로 나눈다.

A형. 일반 세로쓰기 본문
- 한글·한자가 세로로 배열된 일반 본문.
- 편집 가능한 문자로 OCR한다.

B형. 본문 + 그림
- 본문 옆이나 위아래에 삽화·산형도·나경도 등이 있는 페이지.
- 본문은 OCR하고 그림은 이미지로 유지한다.

C형. 원형 나경도·방위도
- 문자가 원형 또는 방사형으로 배열된 도형.
- 전체 도형은 원본 이미지로 유지한다.
- 도형 밖의 제목·번호·설명문은 OCR한다.

D형. 표
- 행과 열로 구성된 자료.
- 구조가 명확하면 편집 가능한 표로 재작성한다.
- 구조가 복잡하거나 글자가 불분명하면 원본 이미지로 유지한다.
- 표 주변의 독립된 설명문은 OCR한다.

E형. 선형 계통도·관계도
- 선·화살표·괄호·박스가 문자를 연결하는 도식.
- 공간적 관계를 보존해야 하므로 이미지 삽입을 우선한다.
- 도식 밖의 설명문은 OCR한다.

F형. 산도·지형도·삽화
- 산맥·물길·혈처·방위 등이 그림 안에 표시된 자료.
- 그림은 이미지로 유지한다.
- 그림 내부 글자를 본문에 따로 나열하지 않는다.

G형. 도표 중심 페이지
- 본문보다 도표 비중이 큰 페이지.
- 도표는 원본 이미지로 보존한다.
- 독립된 제목·설명문·주석이 있으면 해당 부분은 별도로 OCR한다.

그림이 크거나 본문이 적다는 이유만으로 본문까지 이미지 처리하여 문자화를 생략하지 않는다.


## 4. 세로쓰기 읽기 순서 판정

전통적인 세로쓰기의 기본 독서 순서는 다음과 같다.

열 사이의 이동: 오른쪽 열 → 왼쪽 열
각 열 안의 이동: 위 → 아래

예시:

오른쪽 첫째 열: 위에서 아래로 읽음.
그 왼쪽 둘째 열: 위에서 아래로 읽음.
그 왼쪽 셋째 열: 위에서 아래로 읽음.
이 순서로 왼쪽 마지막 열까지 읽음.

같은 높이에 있는 글자를 좌우로 연결하지 않는다.

다만 모든 영역에 같은 방향을 기계적으로 적용하지 않는다. 가로쓰기 제목, 표, 도식, 쌍행소주, 위아래로 나뉜 단 등이 있으면 원본 배열에 따라 읽기 순서를 따로 확인한다.


## 5. 세로쓰기 OCR 작업 절차

각 페이지는 다음 순서로 작업한다.

1단계. 판면 확인
- 본문 시작과 끝을 확인한다.
- 열 개수와 열 경계를 확인한다.
- 제목·주석·그림·표·쪽번호를 구분한다.
- 머리말·꼬리말과 본문을 구분한다.

2단계. 영역 및 열 경계 확정
- 서로 다른 영역의 문자를 섞지 않는다.
- 각 세로 열의 좌우 경계를 확인한다.
- 좁은 열이나 작은 주석을 인접한 본문 열과 합치지 않는다.

3단계. 독립 판독
- 오른쪽 본문 열부터 위→아래 순서로 판독한다.
- 한 열을 끝낸 후 다음 왼쪽 열로 이동한다.
- 제목·본문·주석을 구분하여 입력한다.

4단계. 문장 연결
- 인쇄상의 열 바꿈 때문에 끊긴 문장은 연결한다.
- 실제 문단 구분은 유지한다.
- 다른 영역의 문장을 임의로 합치지 않는다.

5단계. 문맥 확인
- 조사가 비정상적인지 확인한다.
- 한자어가 성립하는지 확인한다.
- 문장이 갑자기 끊기거나 중복되는지 확인한다.
- 열 순서가 뒤바뀌었을 가능성을 확인한다.

이상이 발견되면 먼저 원본의 열 순서와 자형을 다시 확인한다. 문맥만으로 문장을 고쳐 쓰지 않는다.


## 6. 한글·한자 혼용문 보존

한글과 한자가 혼용된 문장은 원문 그대로 유지한다.

예시:

원문:
山은 높고 水는 낮으며 氣는 그 사이에서 行한다.

허용되지 않는 변환:
산은 높고 물은 낮으며 기는 그 사이에서 행한다.
山高水低……
산은 높고 물은 낮으므로 기운이 흐른다.

한글 부분은 한글로, 한자 부분은 한자로 입력한다.

OCR과 번역·현대어 풀이·윤문은 별개의 작업이다. 별도 요청이 없으면 번역하거나 문장을 현대적으로 고쳐 쓰지 않는다.


## 7. 한자 판독 원칙

한자를 판독할 때는 다음을 함께 검토한다.

1) 실제 획과 부수
2) 앞뒤 문맥
3) 해당 분야의 전문용어

문맥이나 전문용어가 유력해도 이미지에서 해당 자형을 확인할 수 없으면 확정하지 않는다.

주의할 유사 한자:

土 / 士
日 / 目
未 / 末
己 / 已 / 巳
干 / 千
人 / 入
口 / 囗
木 / 本 / 末
王 / 玉
己 / 乙
方 / 万
正 / 止
甲 / 申
龍 / 龍의 약자형
氣 / 气

희귀 한자나 이체자는 추측하지 않는다. 원형 보존이 필요한 경우 인쇄된 형태를 유지하고, 정확한 입력이 어려우면 판독 표시와 해당 이미지 위치를 남긴다.


## 8. 한글 OCR 주의사항

한글과 한자의 자형이 비슷하게 보일 때는 문맥보다 원본 글자의 실제 구조를 우선한다.

우선 확인할 오인식 후보:

고 / 古 / 告
이 / 二
을 / 乙
가 / 加
다 / 多
하 / 下
기 / 己
자 / 子
인 / 人

위 목록은 자동 치환표가 아니다. 실제 원본을 확인한 경우에만 수정한다.

한글이 ᄉ·ᄎ·ᄅ 등의 자모로 분리되어 인식되었으면 원본을 확대하여 음절 구조를 확인한다.

원문에 실제 옛한글이나 독립 자모가 있으면 현대 한글 음절로 임의 변환하지 않는다.

옛 맞춤법·어미·표현을 현재 맞춤법에 맞게 고쳐 쓰지 않는다.


## 9. 그림과 본문의 분리 원칙

그림 안의 글자를 본문 OCR에 섞지 않는다.

예를 들어 위쪽에 나경도가 있고 아래쪽에 설명문이 있으면 다음과 같이 처리한다.

- 나경도: 이미지 보존
- 아래 설명문: 문자 OCR
- 그림 밖 제목과 번호: 문자 OCR
- 그림 내부 방위·간지·별 이름 등: 그림 안에서 보존

최종 배치 예시:

그림 제목

[해당 원본 그림 이미지]

설명 본문……

이미지 자리표시는 작업 중 위치를 나타내는 표식이다. 최종 문서에서 실제 이미지가 들어가지 않았으면 그림 삽입 완료로 보고하지 않는다.


## 10. 나경도·원형 도표 처리

원형 나경도와 방위도는 기본적으로 이미지 보존 대상이다.

다음 요소의 위치 관계를 유지한다.

- 二十四山
- 天干·地支
- 八卦
- 五行
- 九星
- 방위
- 내반·외반
- 원주형 문자
- 방사형 선
- 중심점
- 원 내부 및 외곽 주기

이를 일반 텍스트로 풀어쓰면 위치 관계가 사라질 수 있으므로 무리하게 문자화하지 않는다.

별도로 OCR할 영역:
- 그림 밖의 제목
- 그림 번호
- 그림 옆 설명
- 그림 아래 주석

예시:

第十一層 穿山宿

[원본 나경도 이미지]

설명문……

그림 내부 문자 전사가 별도로 요청된 경우에만 원본 이미지와 구분된 별도 전사 자료로 작성한다.


## 11. 산도·지형도 처리

산·물·혈·용맥 등이 표현된 그림은 원본 이미지로 보존한다.

그림 안의 다음 문자를 본문에 독립적으로 나열하지 않는다.

穴
水
山
龍
向

그림 속 표기와 선·물길·산형·혈처의 위치 관계를 유지한다.

그림 밖의 독립된 제목과 설명문은 OCR한다.


## 12. 표 처리 원칙

단순 표:
- 행·열 구조가 명확하다.
- 셀 안의 문자를 판독할 수 있다.
- 셀 병합 관계를 확인할 수 있다.
→ 편집 가능한 표로 복원한다.

복잡한 표:
- 셀 병합이 많다.
- 작은 글자가 밀집되어 있다.
- 괘상·방위·연결선이 함께 있다.
- 여러 표가 중첩되어 있다.
- 셀 경계나 항목 대응관계가 불확실하다.
→ 원본 이미지로 보존한다.

표를 문자화할 때는 다음을 지킨다.

- 원본의 행과 열 방향을 먼저 확인한다.
- 항목명과 값의 대응관계를 유지한다.
- 빈칸을 임의로 채우지 않는다.
- 확인되지 않은 셀을 임의로 병합하지 않는다.
- 표를 일반 문장으로 바꾸어 항목 관계를 없애지 않는다.
- 표 주변의 독립된 설명문은 별도로 OCR한다.


## 13. 괘상·기호 처리

괘상과 음양효는 일반 문자와 구분한다.

예시:
☰ ☱ ☲ ☳ ☴ ☵ ☶ ☷

음양효가 다음과 같이 오인식될 수 있으므로 주의한다.

===
---
111
lll

위와 같은 OCR 문자열을 그대로 본문에 넣지 않는다.

괘상의 효 수·끊김·위아래 순서를 확인할 수 없으면 추정하지 않는다.

괘상 자체의 모양과 위치가 중요하면 원본 이미지로 보존한다. 문자 기호로 대체하는 경우에도 원본과 같은 괘인지 확인해야 한다.


## 14. 숫자 판독

숫자·연도·쪽수·조문 번호·각도·도수·분량은 이미지에서 직접 확인한다.

주의할 문자:

一 / 二 / 三
七 / 十
0 / O
1 / I / l
2 / Z
5 / S
6 / G
8 / B

풍수·역학 문헌의 숫자는 방위·운수·괘상·도표 해석과 연결되므로 문맥상 예상되는 숫자로 채우지 않는다.

원본에서 숫자를 확인할 수 없으면 판독불명 표시를 남긴다.


## 15. 쪽번호 처리

인쇄 쪽번호는 본문과 분리한다.

예시:
- 230 -

이 표기가 문장 중간에 삽입되지 않도록 한다.

페이지 기록에는 가능한 한 다음을 함께 남긴다.

- 원본 파일명
- 파일 내부 PDF 쪽수
- 분할 전 전체 PDF 쪽수
- 실제 인쇄 쪽수

확인되지 않은 쪽수는 추정하여 확정하지 않는다.

표시 예시:
[전체 PDF 251쪽 / 분할 PDF 1쪽 / 인쇄 230쪽]

책 본문의 인쇄 쪽수와 PDF 파일 쪽수를 혼동하지 않는다.


## 16. 머리말·꼬리말 처리

페이지마다 반복되는 책 제목·장 제목·쪽번호 등은 본문에서 분리한다.

다만 다음은 원문 내용이므로 삭제하지 않는다.

- 실제 장이 시작되는 제목
- 표제지의 서명·저자명·출판사명
- 판권지의 발행 및 인쇄 정보
- 서문 끝의 날짜·서명
- 본문에 포함된 출판·인쇄 관련 설명

반복되는 페이지 장식인지, 원문의 실제 내용인지 먼저 확인한다.


## 17. 제목 처리

원본의 제목 계층과 번호를 유지한다.

예시:

第三章 地理砂法
第一節 人盤中針

원문에 없는 제목·소제목·번호를 추가하지 않는다.

세로쓰기 제목은 최종 문서에서 가로쓰기 제목으로 입력할 수 있다.

제목을 문맥만 보고 새로 만들거나 기존 번호 체계를 현대식 번호로 바꾸지 않는다.


## 18. 문단 처리

세로 열의 끝은 곧 문단의 끝이 아니다.

예시:

첫째 열 끝:
風水之理

다음 열 시작:
在乎陰陽

문장이 이어지는 경우:
風水之理在乎陰陽

실제 문단 구분은 들여쓰기·빈 공간·문단 시작 표시·제목 변화 등 원본의 근거로 판단한다.

앞뒤 페이지로 문장이 이어지면 문장 연결을 확인하되 페이지 경계 기록은 유지한다.

서로 다른 제목 아래의 문장이나 그림 설명을 하나의 본문 문장으로 합치지 않는다.


## 19. 판독 불명 표시

원본에서 확인할 수 없는 글자를 임의로 채우지 않는다.

표기 규칙:

전혀 판독할 수 없음:
〔판독불명〕

한 글자 후보가 있으나 확정할 수 없음:
〔疑: 龍〕

두 후보가 있음:
〔龍/龐〕

원본이 잘렸거나 가려졌거나 훼손됨:
〔원본 결락〕

가능하면 다음 정보를 함께 기록한다.

- 파일명과 쪽수
- 본문 또는 주석 여부
- 오른쪽에서 몇 번째 열인지
- 위에서 어느 구간인지
- 앞뒤의 확인 가능한 문자

판독불명 표시를 문서에서 몰래 삭제하거나 유력한 후보로 일괄 교체하지 않는다.


## 20. 기존 OCR 텍스트가 있는 경우

기존 OCR은 비교·보조 자료로만 사용한다.

작업 순서:

1) 원본 이미지에서 해당 영역을 독립적으로 판독한다.
2) 기존 OCR 결과와 비교한다.
3) 문자·문장부호·문단·열 순서의 차이를 찾는다.
4) 서로 다른 부분을 원본 이미지에서 다시 확인한다.
5) 최종 판독문을 확정한다.

텍스트 레이어가 있는 PDF는 기존 텍스트를 먼저 추출하여 상태를 확인할 수 있다. 다만 추출된 문자열을 이미지 대조 없이 교정 완료 원문으로 확정하지 않는다.

기존 OCR의 품질이 매우 나쁘면 오류 문자열에 끌려가지 말고 원본에서 다시 판독한다.

좌표 정렬만으로 문장 순서를 바꾼 결과는 문자 교정 완료본이 아니다.


## 21. 금지하는 자동 보정

다음 행위를 하지 않는다.

- 한자를 현대 한국어로 번역한다.
- 어려운 한자를 쉬운 한자로 바꾼다.
- 원문 문장을 자연스럽게 다시 작성한다.
- 원문에 없는 조사·어미·접속어를 넣는다.
- 의미를 보고 누락된 글자를 추정하여 채운다.
- 한자어를 익숙한 현대 용어로 교체한다.
- 그림 내부 문자를 본문에 섞는다.
- 나경도를 텍스트 목록으로 바꾼다.
- 확인하지 않은 괘상을 ASCII 문자로 대체한다.
- 표를 임의의 문장으로 바꾸어 대응관계를 없앤다.
- 기존 OCR 오인식 후보를 전역 일괄 치환한다.
- 이미지로 보존한 페이지를 문자 OCR 완료 페이지라고 보고한다.


## 22. OCR 출력 형식

기본 출력 형식:

[원본 파일명 / PDF 쪽수 / 인쇄 쪽수]

원문 제목

원문 소제목

교정 본문……

[해당 위치의 원본 도판 이미지]

교정 설명문……

[판독 확인 필요]
없음 또는 확인이 필요한 부분을 기록.

불확실한 부분이 있으면 다음과 같이 기록한다.

[판독 확인 필요]
오른쪽에서 세 번째 본문 열, 중간 구간:
「○○〔疑: 龍〕○○」

원문에 없는 작업 설명이나 판독 메모는 원문 본문과 명확히 분리한다.


## 23. DOCX/HWPX 제작 시 그림 처리

원본 그림과 관련 본문의 관계를 유지한다.

권장 구조:

원문 제목
관련 본문
원본 그림 이미지
그림 설명
이어지는 본문

다만 위 순서를 모든 페이지에 기계적으로 적용하지 말고 원본의 의미 흐름과 배치를 따른다.

- 그림을 문서 끝에 몰아서 넣지 않는다.
- 원본 이미지의 가로세로 비율을 유지한다.
- 그림 외곽 문자·제목·번호가 잘리지 않도록 한다.
- 그림을 지나치게 작게 넣어 글자가 읽히지 않게 하지 않는다.
- 본문까지 포함된 큰 이미지와 같은 본문 OCR을 무분별하게 중복 수록하지 않는다.
- 대조용 원본 페이지를 함께 넣는 경우에는 교정 본문과 구분한다.

실제 문서 파일을 생성하지 못했으면 생성했다고 보고하지 않는다.

DOCX의 확장자만 HWPX로 바꾸지 않는다. 요청한 형식의 실제 파일 구조로 생성된 경우에만 해당 형식의 결과물이라고 보고한다.


## 24. 이미지 품질과 확대 확인

작은 글자가 있는 경우 전체 페이지 축소 이미지만 보고 추측하지 않는다.

확인 순서:

전체 페이지
→ 해당 영역
→ 해당 열
→ 해당 문장
→ 해당 글자

우선 확대할 대상:

- 희귀 한자
- 작은 주석
- 숫자·각도·도수
- 干支·二十四山
- 괘상
- 표 셀 내부 문자
- 본문과 도판의 경계에 있는 문자

이미지 확대는 자형 확인을 돕는 수단이다. 확대만으로 원본에 없던 세부 획이 복원되었다고 판단하지 않는다.

도판 이미지 보존 과정에서는 외곽 문자와 기호가 잘리지 않았는지 확인한다.


## 25. 여러 페이지 작업 시 권장 단위

일반 본문:
3~5쪽씩 판독·대조·교정한다.

표·주석·희귀 한자가 많거나 판면이 복잡한 부분:
1~3쪽씩 처리한다.

독립 본문이 거의 없는 나경도·도판 연속 구간:
5~10쪽씩 이미지 보존 상태를 확인할 수 있다.

한 번에 수백 쪽을 자동 OCR한 뒤 최종 교정본으로 간주하지 않는다.

작업 구간이 바뀔 때 앞 구간의 마지막 문장과 다음 구간의 첫 문장을 확인한다.

배치 단위는 작업 관리 기준이며, 실제로 처리하지 않은 다음 구간을 완료했다고 기록하지 않는다.


## 26. 페이지별 품질검사

각 페이지는 다음 순서로 검사한다.

1차. 구조 검사
- 읽기 순서가 맞는가?
- 제목과 본문이 구분되는가?
- 본문·주석·도판 문자가 섞이지 않았는가?
- 문단과 도표 위치가 보존되었는가?
- 누락된 영역이 없는가?

2차. 문자 검사
- 한글 음절이 정확한가?
- 한자 자형이 정확한가?
- 숫자와 기호가 정확한가?
- 중복 또는 누락 문자가 없는가?
- 이체자와 희귀자가 임의로 바뀌지 않았는가?

3차. 문맥 검사
- 열과 페이지 사이의 문장이 올바르게 이어지는가?
- 조사나 어미의 이상이 OCR 오류 때문인지 원문 표현인지 확인했는가?
- 도판 설명을 일반 본문과 잘못 연결하지 않았는가?

4차. 원본 재대조
- 기존 OCR과 크게 달라진 부분을 다시 확인한다.
- 수정한 글자의 실제 자형을 재확인한다.
- 판독불명 표시가 필요한 곳을 확정 문자로 쓰지 않았는지 확인한다.


## 27. 최종 전수 교감

전수 교감 요청을 받은 경우 우선 확인 항목만 골라 보는 것으로 끝내지 않는다.

대상 본문의 모든 문자를 원본 이미지와 순서대로 대조한다.

특히 다음은 추가 점검한다.

- 제목
- 전문용어
- 인명
- 서명
- 고유명사
- 숫자
- 방위
- 天干·地支
- 二十四山
- 괘명
- 五行
- 九星
- 도표 제목
- 주석

자동 검사·표본 검사·렌더링 검사는 전수 문자 대조를 대신하지 않는다.

문서가 정상적으로 열리거나 전체 쪽수가 맞는다는 사실만으로 OCR 정확성이 검증되었다고 판단하지 않는다.


## 28. 오류가 많은 영역의 처리

다음과 같은 경우 기존 OCR 문자열을 수정하는 데만 매달리지 말고 해당 영역을 원본에서 다시 판독한다.

- 한 문장에 여러 오인식이 연속된다.
- 한글과 한자가 비정상적으로 뒤섞인다.
- 세로 열 순서가 무너져 있다.
- 글자가 한글 자모나 특수기호로 대량 변환되었다.
- 표가 무관한 문자열로 붕괴되었다.
- 그림 내부 글자가 본문에 섞였다.

기존 OCR 결과를 폐기하더라도 원본 영역을 생략해서는 안 된다.

다시 판독할 수 없는 부분은 불확실 표시와 위치 기록을 남긴다.


## 29. 그림 보존 판단 기준

다음 항목을 확인한다.

- 문자의 위치 자체가 의미를 가지는가?
- 선과 문자 사이의 관계가 중요한가?
- 원형 또는 방사형 배열인가?
- 방향이 중요한가?
- 괘상·도형·연결선이 포함되어 있는가?
- 문자로 풀면 공간적 정보가 사라지는가?
- 편집 가능한 형태로 복원할 때 원래 대응관계를 확실히 유지할 수 있는가?

공간적 관계를 신뢰성 있게 복원할 수 없으면 이미지로 보존한다.

단순 표는 셀 위치가 중요하더라도 정확한 표 구조로 복원할 수 있으면 편집 가능한 표로 작성할 수 있다.


## 30. 그림과 본문 분리 예시

원본 구성:

第十一層 穿山宿
[복잡한 원형 나경도]
穿山七十二龍……

잘못된 처리:

第十一層 穿山宿
甲乙丙丁戊……
子丑寅卯……
그림 내부 문자들을 임의 순서로 나열……
穿山七十二龍……

올바른 처리:

第十一層 穿山宿

[원본 나경도 이미지]

穿山七十二龍……

도판은 위치 관계를 보존하고, 도판 밖 본문은 편집 가능한 문자로 작성한다.


## 31. 표 처리 예시

원본이 다음과 같은 단순 표라면:

甲山 | 庚山 | 丙山
항목 | 항목 | 항목

행·열 대응관계를 그대로 유지하여 편집 가능한 표로 복원한다.

하지만 셀 내부에 괘상·방위·연결선·다층 배열이 복합적으로 들어 있고 정확한 재구성이 어렵다면 원본 이미지로 유지한다.

이미지로 보존한 표의 내용을 OCR한 것처럼 별도 문자열로 임의 생성하지 않는다.


## 32. 결과물 유형 구분

A. 원형 보존 OCR본
- 한글·한자·이체자와 원문의 표현을 보존한다.
- 명백한 OCR 오인식만 수정한다.
- 도식은 원본 이미지로 보존한다.
- 원문의 문장부호도 가능한 한 유지한다.

B. 편집용 교정본
- OCR 오인식을 수정한다.
- 인쇄상의 불필요한 줄바꿈을 정리한다.
- 실제 문단과 제목 구조를 유지한다.
- 그림·표와 본문의 관계를 정리한다.
- 문장부호·정자 통일은 사용자가 지정한 규칙이 있을 때 적용한다.
- 통일 규칙이 없으면 임의의 대규모 문자 치환을 하지 않는다.

기본 결과물은 편집용 교정본으로 하되, 원문 어휘·표현·한글과 한자의 구분은 유지한다.


## 33. 작업 상태와 완료 보고

작업 상태를 구분하여 기록한다.

- 미처리
- 영역 분류 완료
- 1차 OCR 완료
- 원본 대조 완료
- 판독 확인 필요
- 이미지 보존 확인 완료
- 문서 반영 완료
- 파일 구조 검사 완료

"완료"는 실제 확인한 범위에 한정하여 사용한다.

보고 예시:

PDF 1~5쪽:
본문 원본 대조 및 문서 반영 완료.

PDF 6쪽:
도판 이미지 보존 확인 완료.
도판 내부 문자 전사는 수행하지 않음.

PDF 7쪽:
본문 OCR 완료.
희귀 한자 2자는 판독 확인 필요.

PDF 8쪽 이후:
미처리.

다음 행위를 금지한다.

- 일부만 작업하고 전체 완료라고 보고한다.
- 자동 OCR만 수행하고 전수 교감 완료라고 보고한다.
- 전체 페이지를 이미지로 넣고 전체 문자 OCR 완료라고 보고한다.
- 실제 생성되지 않은 파일이나 다운로드 링크를 제시한다.
- 실행 수단 없이 답변 이후에도 작업이 자동으로 계속된다고 안내한다.


## 34. Gemini용 핵심 명령

원본 이미지를 최종 증거로 사용하라.

기존 OCR 문자열을 정답으로 신뢰하지 말라.

먼저 페이지와 영역을 일반 본문, 제목, 주석, 표, 원형 나경도, 산도·지형도, 기타 도식으로 나누어라.

일반 세로쓰기 본문은 원본 배열을 확인한 후 오른쪽 열에서 왼쪽 열로, 각 열은 위에서 아래로 판독하라.

한글과 한자를 원문 그대로 구분하여 입력하라.

그림·나경도·산도·복잡한 표처럼 위치 관계 자체가 의미를 가지는 자료는 억지로 문자화하지 말고 이미지로 유지하라.

그림 밖의 독립된 제목·설명문·주석은 별도로 OCR하라.

판독할 수 없는 글자를 문맥으로 보충하지 말고 불확실 표시를 남겨라.

실제 원본 대조가 끝난 범위만 교정 완료로 보고하라.


## 35. 페이지 처리 전 점검 항목

각 페이지를 처리하기 전에 다음을 확인한다.

1) 이 페이지에는 어떤 유형의 영역이 있는가?
2) 각 영역의 읽기 방향은 무엇인가?
3) 오른쪽 첫 번째 본문 열은 어디인가?
4) 제목·본문·주석의 경계는 어디인가?
5) 그림 안의 문자가 본문에 섞일 위험이 있는가?
6) 표를 문자화해도 항목 대응관계가 보존되는가?
7) 도판 밖 설명문을 빠뜨리지 않았는가?
8) 원본에서 확인할 수 없는 글자가 있는가?
9) 앞뒤 페이지로 이어지는 문장이 있는가?

점검 결과를 작업에 반영하되, 매 페이지마다 긴 판단 과정을 출력할 필요는 없다. 사용자에게는 결과와 확인이 필요한 사항을 보고한다.


## 36. 최종 품질 기준

최종 결과물은 다음 조건을 충족해야 한다.

첫째, 읽기 순서가 원본과 일치해야 한다.

둘째, 원본에 없는 글자가 추가되지 않아야 한다.

셋째, 원본에 있는 본문이 누락되지 않아야 한다.

넷째, 한글과 한자의 구분이 유지되어야 한다.

다섯째, 그림 내부 문자와 본문이 섞이지 않아야 한다.

여섯째, 표와 도식의 공간적 의미가 보존되어야 한다.

일곱째, 판독하지 못한 글자를 확정된 글자처럼 쓰지 않아야 한다.

여덟째, 실제 문단과 제목 구조가 유지되어야 한다.

아홉째, 문서 배치 검사와 문자 정확성 검사를 구분해야 한다.

열째, 실제로 수행한 작업과 보고한 완료 범위가 일치해야 한다.

최종 원칙:
"문장이 자연스럽다"보다 "원본과 일치한다"가 우선이다.


# 매 작업 시 사용하는 실행 프롬프트

첨부한 PDF 또는 이미지를 위 프로젝트 지침에 따라 OCR하고 원본과 대조하여 교정하라.

먼저 작업 대상 파일과 쪽수를 확인하라. PDF 쪽수와 실제 인쇄 쪽수를 구분하여 기록하라.

각 페이지 전체를 단일 유형으로 처리하지 말고 일반 본문, 제목, 주석, 표, 원형 나경도, 산도·지형도, 기타 도식의 영역을 구분하라.

일반 본문·제목·독립된 설명문·주석은 편집 가능한 문자로 작성하라. 원형 나경도·산도·복잡한 표·위치 관계가 중요한 도식은 원본 이미지로 유지하라.

그림이 있는 페이지에서도 그림 밖 본문과 설명문은 생략하지 말고 OCR하라. 그림 내부 글자를 일반 본문에 섞지 마라.

세로쓰기 본문은 원본에서 읽기 순서를 확인하고 오른쪽 열부터 왼쪽 열로, 각 열은 위에서 아래로 판독하라. 한글과 한자를 원문 그대로 보존하라.

기존 OCR 문자열이나 PDF 텍스트 레이어가 있어도 이를 정답으로 간주하지 마라. 원본 이미지의 자형을 최종 기준으로 삼아 비교·교정하라.

판독이 불확실한 부분은 추측하지 말고 〔판독불명〕, 〔疑: ○〕, 〔○/△〕, 〔원본 결락〕으로 표시하라. 해당 쪽수와 위치를 기록하라.

실제 문단은 유지하고 인쇄상의 단순 열 바꿈은 연결하라. 쪽번호와 반복 머리말·꼬리말은 본문에서 분리하라. 원문의 어휘·조사·어미·옛 맞춤법을 임의로 현대화하지 마라.

도판은 관련 본문 가까이에 배치하고, 가로세로 비율을 유지하며 외곽 문자와 기호가 잘리지 않게 하라. 최종 문서에는 자리표시뿐 아니라 실제 원본 이미지를 삽입하라.

일반 본문은 3~5쪽, 표·주석·도식이 복잡한 부분은 1~3쪽 단위로 원본과 대조하라. 각 구간에서 구조 검사, 문자 검사, 문맥 검사, 수정 부분 재대조를 수행하라.

전수 교감 요청이면 본문의 모든 문자를 순서대로 대조하라. 표본 검사, 좌표 정렬, 자동 치환, 문서 렌더링만으로 전수 교감했다고 보고하지 마라.
